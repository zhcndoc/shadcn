## 用法

```tsx showLineNumbers
import { Button } from "@/components/ui/button"
import {
  Dialog,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"
```

```tsx showLineNumbers
<DialogTrigger>
  <Button>打开</Button>
  <Dialog>
    <DialogHeader>
      <DialogTitle>你确定要继续吗？</DialogTitle>
      <DialogDescription>
        此操作无法撤销。这将永久删除你的账户，并从我们的服务器中移除你的数据。
      </DialogDescription>
    </DialogHeader>
  </Dialog>
</DialogTrigger>
```

## 组合

使用以下组合来构建一个 `Dialog`：

```text
DialogTrigger
├── Button
└── Dialog
    ├── DialogHeader
    │   ├── DialogTitle
    │   └── DialogDescription
    └── DialogFooter
```
