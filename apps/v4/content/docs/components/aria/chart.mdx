介绍一下**图表**。这是一组图表组件，你可以将其复制并粘贴到你的应用中。

图表开箱即用，外观精美。它们与其他组件配合良好，并且可以完全自定义，以适应你的项目。

[浏览图表库](/charts)。

## 组件

我们在底层使用 [Recharts](https://recharts.org/)。

我们在设计 `chart` 组件时考虑了组合性。**你可以使用 Recharts 组件构建图表，并且仅在需要时、需要的位置引入自定义组件，例如 `ChartTooltip`**。

```tsx showLineNumbers /ChartContainer/ /ChartTooltipContent/
import { Bar, BarChart } from "recharts"

import { ChartContainer, ChartTooltipContent } from "@/components/ui/chart"

export function MyChart() {
  return (
    <ChartContainer>
      <BarChart data={data}>
        <Bar dataKey="value" />
        <ChartTooltip content={<ChartTooltipContent />} />
      </BarChart>
    </ChartContainer>
  )
}
```

我们不会对 Recharts 进行封装。这意味着你不会被锁定在某种抽象之中。当 Recharts 发布新版本时，你可以遵循官方的升级路径来升级你的图表。

**这些组件属于你**。

## 图表配置

图表配置用于定义图表的标签、图标和颜色。

它与图表数据刻意解耦。

这样可以在多个图表之间共享配置和颜色令牌。对于数据或颜色令牌存储在远程位置或采用不同格式的情况，它也可以独立工作。

```tsx showLineNumbers /ChartConfig/
import { Monitor } from "lucide-react"

import { type ChartConfig } from "@/components/ui/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    icon: Monitor,
    // 类似 'hsl(220, 98%, 61%)' 或 'var(--color-name)' 的颜色
    color: "#2563eb",
    // 或者使用包含 'light' 和 'dark' 键的主题对象
    theme: {
      light: "#2563eb",
      dark: "#dc2626",
    },
  },
} satisfies ChartConfig
```

## 主题

图表内置了主题支持。你可以使用 CSS 变量（推荐），也可以使用任意颜色格式的颜色值，例如 hex、hsl 或 oklch。

### hex、hsl 或 oklch

你也可以直接在图表配置中定义颜色。使用你偏好的颜色格式。

```tsx title="components/example-chart.tsx" showLineNumbers
const chartConfig = {
  desktop: {
    label: "Desktop",
    color: "#2563eb",
  },
  mobile: {
    label: "Mobile",
    color: "hsl(220, 98%, 61%)",
  },

  },
  laptop: {
    label: "Laptop",
    color: "var(--chart-2)",
  },

```

### 使用颜色

要在图表中使用主题颜色，请使用 `var(--color-KEY)` 格式引用颜色。

#### 组件

```tsx
<Bar dataKey="desktop" fill="var(--color-desktop)" />
```

#### 图表数据


## 工具提示

图表工具提示包含标签、名称、指示器和值。你可以组合使用这些内容来自定义工具提示。

<ComponentPreview styleName="aria-nova" name="chart-tooltip" hideCode />

你可以使用 `hideLabel`、`hideIndicator` 属性开启或关闭其中任意内容，并使用 `indicator` 属性自定义指示器样式。

使用 `labelKey` 和 `nameKey` 为工具提示标签和名称使用自定义键。

图表提供了 `<ChartTooltip>` 和 `<ChartTooltipContent>` 组件。你可以使用这两个组件为图表添加自定义工具提示。

```tsx title="components/example-chart.tsx"
import { ChartTooltip, ChartTooltipContent } from "@/components/ui/chart"
```

```tsx title="components/example-chart.tsx"
<ChartTooltip content={<ChartTooltipContent />} />
```

### 属性

使用以下属性自定义工具提示。

| 属性            | 类型                     | 描述                                  |
| :-------------- | :----------------------- | :------------------------------------------- |
| `labelKey`      | string                   | 用于标签的配置键或数据键。 |
| `nameKey`       | string                   | 用于名称的配置键或数据键。  |
| `indicator`     | `dot` `line` 或 `dashed` | 工具提示的指示器样式。         |
| `hideLabel`     | boolean                  | 是否隐藏标签。                   |
| `hideIndicator` | boolean                  | 是否隐藏指示器。               |

### 颜色

颜色会自动从图表配置中引用。

### 自定义

要为工具提示标签和名称使用自定义键，请使用 `labelKey` 和 `nameKey` 属性。

```tsx showLineNumbers /browser/
const chartData = [
  { browser: "chrome", visitors: 187, fill: "var(--color-chrome)" },
  { browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]

const chartConfig = {
  visitors: {
    label: "Total Visitors",
  },
  chrome: {
    label: "Chrome",
    color: "var(--chart-1)",
  },
  safari: {
    label: "Safari",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

```tsx title="components/example-chart.tsx"
<ChartTooltip
  content={<ChartTooltipContent labelKey="visitors" nameKey="browser" />}
/>
```

这将使用 `Total Visitors` 作为标签，并使用 `Chrome` 和 `Safari` 作为工具提示名称。

## 无障碍访问

你可以启用 `accessibilityLayer` 属性，为图表添加无障碍访问层。

此属性为图表添加键盘访问和屏幕阅读器支持。

```tsx title="components/example-chart.tsx"
<LineChart accessibilityLayer />
```
