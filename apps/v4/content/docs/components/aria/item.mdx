## 用法

```tsx showLineNumbers
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item"
```

```tsx showLineNumbers
<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>
```

## 组合

使用以下组合来构建一个 `Item`：

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemMedia
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions
    └── ItemFooter
```

## Item 与 Field

如果需要显示复选框、输入框、单选框或选择框等表单输入控件，请使用 `Field`。

如果只需要显示标题、描述和操作等内容，请使用 `Item`。

## API 参考

### Item

用于显示带有媒体、标题、描述和操作的内容的主要组件。

| 属性      | 类型                                | 默认值     |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size`    | `"default" \| "sm" \| "xs"`         | `"default"` |
| `render`  | `React.ReactElement`                |             |

### ItemGroup

用于将相关项目组合在一起并保持样式一致的容器。

```tsx
<ItemGroup>
  <Item />
  <Item />
</ItemGroup>
```

### ItemSeparator

组内项目之间的分隔符。

```tsx
<ItemGroup>
  <Item />
  <ItemSeparator />
  <Item />
</ItemGroup>
```

### ItemMedia

使用 `ItemMedia` 显示图标、图像或头像等媒体内容。

| 属性      | 类型                             | 默认值     |
| --------- | -------------------------------- | ----------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |

```tsx
<ItemMedia variant="icon">
  <Icon />
</ItemMedia>
```

```tsx
<ItemMedia variant="image">
  <img src="..." alt="..." />
</ItemMedia>
```

### ItemContent

用于包裹项目的标题和描述。

```tsx
<ItemContent>
  <ItemTitle>标题</ItemTitle>
  <ItemDescription>描述</ItemDescription>
</ItemContent>
```

### ItemTitle

显示项目的标题。

```tsx
<ItemTitle>项目标题</ItemTitle>
```

### ItemDescription

显示项目的描述。

```tsx
<ItemDescription>项目描述</ItemDescription>
```

### ItemActions

用于放置操作按钮或其他交互元素的容器。

```tsx
<ItemActions>
  <Button>操作</Button>
</ItemActions>
```

### ItemHeader

在项目内容上方显示页眉。

```tsx
<Item>
  <ItemHeader>页眉</ItemHeader>
  <ItemContent>...</ItemContent>
</Item>
```

### ItemFooter

在项目内容下方显示页脚。

```tsx
<Item>
  <ItemContent>...</ItemContent>
  <ItemFooter>页脚</ItemFooter>
</Item>
```
