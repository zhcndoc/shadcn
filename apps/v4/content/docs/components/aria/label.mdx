
## 字段中的标签

对于表单字段，请使用 [Field](/docs/components/aria/field) 组件，其中包含内置的 `FieldLabel`、`FieldDescription` 和 `FieldError` 组件。

```tsx
<Field>
  <FieldLabel htmlFor="email">Your email address</FieldLabel>
  <Input id="email" />
</Field>
```
