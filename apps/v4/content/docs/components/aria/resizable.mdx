## 用法

```tsx showLineNumbers
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```tsx showLineNumbers
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel>One</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel>Two</ResizablePanel>
</ResizablePanelGroup>
```

## 组合

使用以下组合来构建一个 `ResizablePanelGroup`：

```text
ResizablePanelGroup
├── ResizablePanel
├── ResizableHandle
└── ResizablePanel
```

## 更新日志

### 2025-02-02 `react-resizable-panels` v4

已更新至 `react-resizable-panels` v4。完整详情请参阅 [v4.0.0 发布说明](https://github.com/bvaughn/react-resizable-panels/releases/tag/4.0.0)。

如果你直接使用 `react-resizable-panels` 原语，请注意以下更改：

| v3                           | v4                      |
| ---------------------------- | ----------------------- |
| `PanelGroup`                 | `Group`                 |
| `PanelResizeHandle`          | `Separator`             |
| `direction` prop             | `orientation` prop      |
| `defaultSize={50}`           | `defaultSize="50%"`     |
| `onLayout`                   | `onLayoutChange`        |
| `ImperativePanelHandle`      | `PanelImperativeHandle` |
| Panel 上的 `ref` prop        | `panelRef` prop         |
| `data-panel-group-direction` | `aria-orientation`      |

<Callout>
  shadcn/ui 的包装组件（`ResizablePanelGroup`、`ResizablePanel`、
  `ResizableHandle`）保持不变。
</Callout>
