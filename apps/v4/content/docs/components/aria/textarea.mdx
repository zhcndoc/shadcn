使用 `Field`、`FieldLabel` 和 `FieldDescription` 创建带有标签和描述的文本区域。

## 禁用

使用 `disabled` 属性禁用文本区域。要设置禁用状态的样式，请将 `data-disabled` 属性添加到 `Field` 组件。

<ComponentPreview
  styleName="aria-nova"
  name="textarea-disabled"
  previewClassName="*:max-w-xs"
/>

## 无效

使用 `aria-invalid` 属性将文本区域标记为无效。要设置无效状态的样式，请将 `data-invalid` 属性添加到 `Field` 组件。

<ComponentPreview
  styleName="aria-nova"
  name="textarea-invalid"
  previewClassName="*:max-w-xs"
/>
