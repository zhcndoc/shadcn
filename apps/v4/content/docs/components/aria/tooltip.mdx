## 用法

```tsx showLineNumbers
import { Tooltip, TooltipTrigger } from "@/components/ui/tooltip"
```

```tsx showLineNumbers
<TooltipTrigger>
  <Button>悬停</Button>
  <Tooltip>
    <p>添加到库</p>
  </Tooltip>
</TooltipTrigger>
```

## 组合

使用以下组合构建一个 `Tooltip`：

```text
TooltipTrigger
├── Button
└── Tooltip
```
