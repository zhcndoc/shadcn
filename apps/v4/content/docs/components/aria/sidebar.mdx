## 用法

```tsx showLineNumbers title="app/layout.tsx"
import { SidebarProvider, SidebarTrigger } from "@/components/ui/sidebar"
import { AppSidebar } from "@/components/app-sidebar"

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <AppSidebar />
      <main>
        <SidebarTrigger />
        {children}
      </main>
    </SidebarProvider>
  )
}
```

## 结构

- **SidebarProvider** — 处理可折叠状态，并向子组件提供侧边栏上下文。
- **Sidebar** — 主要的可折叠侧边栏面板。
- **SidebarHeader** — 固定在顶部；用于品牌展示、标题或工作区切换器。
- **SidebarFooter** — 固定在底部；用于用户菜单、设置或操作。
- **SidebarContent** — 页眉和页脚之间的可滚动区域。
- **SidebarGroup** — 将相关导航分组，并可包含标签、操作和内容区域。
- **SidebarMenu** / **SidebarMenuItem** — 用于链接、徽章、操作和嵌套子菜单的菜单结构。
- **SidebarRail** — 在适用时用于调整侧边栏宽度的调整手柄。
- **SidebarInset** — 使用 `inset` 变体时包裹主要内容。
- **SidebarTrigger** — 用于切换侧边栏展开或折叠状态的控件。

## SidebarProvider

`SidebarProvider` 组件用于为 `Sidebar` 组件提供侧边栏上下文。你应始终将应用包裹在 `SidebarProvider` 组件中。

### Props

| 名称           | 类型                      | 描述                                  |
| -------------- | ------------------------- | -------------------------------------------- |
| `defaultOpen`  | `boolean`                 | 侧边栏的默认打开状态。           |
| `open`         | `boolean`                 | 侧边栏的打开状态（受控）。      |
| `onOpenChange` | `(open: boolean) => void` | 设置侧边栏的打开状态（受控）。 |

### 宽度

如果应用中只有一个侧边栏，可以使用 `sidebar.tsx` 中的 `SIDEBAR_WIDTH` 和 `SIDEBAR_WIDTH_MOBILE` 变量来设置侧边栏的宽度。

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_WIDTH = "16rem"
const SIDEBAR_WIDTH_MOBILE = "18rem"
```

如果应用中有多个侧边栏，可以在 `style` 属性中使用 `--sidebar-width` 和 `--sidebar-width-mobile` CSS 变量。

```tsx showLineNumbers
<SidebarProvider
  style={
    {
      "--sidebar-width": "20rem",
      "--sidebar-width-mobile": "20rem",
    } as React.CSSProperties
  }
>
  <Sidebar />
</SidebarProvider>
```

### 键盘快捷键

在 Mac 上使用 `cmd+b` 键盘快捷键，在 Windows 上使用 `ctrl+b` 键盘快捷键来触发侧边栏。

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_KEYBOARD_SHORTCUT = "b"
```

## 侧边栏

用于渲染可折叠侧边栏的主要 `Sidebar` 组件。

### 属性

| 属性          | 类型                              | 描述                         |
| ------------- | --------------------------------- | ---------------------------- |
| `side`        | `left` 或 `right`                 | 侧边栏所在的一侧。           |
| `variant`     | `sidebar`、`floating` 或 `inset` | 侧边栏的变体。               |
| `collapsible` | `offcanvas`、`icon` 或 `none`    | 侧边栏的可折叠状态。         |

| 属性        | 描述                                         |
| ----------- | -------------------------------------------- |
| `offcanvas` | 从左侧或右侧滑入的可折叠侧边栏。             |
| `icon`      | 可折叠为图标的侧边栏。                       |
| `none`      | 不可折叠的侧边栏。                           |

<Callout>
  **注意：** 如果使用 `inset` 变体，请记得将主要内容包裹在
  `SidebarInset` 组件中。
</Callout>

```tsx showLineNumbers
<SidebarProvider>
  <Sidebar variant="inset" />
  <SidebarInset>
    <main>{children}</main>
  </SidebarInset>
</SidebarProvider>
```

## useSidebar

`useSidebar` hook 用于控制侧边栏。

```tsx showLineNumbers
import { useSidebar } from "@/components/ui/sidebar"

export function AppSidebar() {
  const {
    state,
    open,
    setOpen,
    openMobile,
    setOpenMobile,
    isMobile,
    toggleSidebar,
  } = useSidebar()
}
```

| Property        | Type                      | Description                                   |
| --------------- | ------------------------- | --------------------------------------------- |
| `state`         | `expanded` or `collapsed` | 侧边栏的当前状态。             |
| `open`          | `boolean`                 | 侧边栏是否打开。                  |
| `setOpen`       | `(open: boolean) => void` | 设置侧边栏的打开状态。           |
| `openMobile`    | `boolean`                 | 侧边栏在移动设备上是否打开。        |
| `setOpenMobile` | `(open: boolean) => void` | 设置侧边栏在移动设备上的打开状态。 |
| `isMobile`      | `boolean`                 | 侧边栏是否位于移动设备上。             |
| `toggleSidebar` | `() => void`              | 切换侧边栏。适用于桌面端和移动端。      |

## SidebarGroup

使用 `SidebarGroup` 组件在侧边栏中创建一个分区。

`SidebarGroup` 包含一个 `SidebarGroupLabel`、一个 `SidebarGroupContent` 和一个可选的 `SidebarGroupAction`。

```tsx showLineNumbers
<SidebarGroup>
  <SidebarGroupLabel>应用程序</SidebarGroupLabel>
  <SidebarGroupAction>
    <Plus /> <span className="sr-only">添加项目</span>
  </SidebarGroupAction>
  <SidebarGroupContent></SidebarGroupContent>
</SidebarGroup>
```

要使 `SidebarGroup` 可折叠，请将其包裹在 `Collapsible` 中。

```tsx showLineNumbers
<Collapsible defaultExpanded className="group/collapsible">
  <SidebarGroup>
    <SidebarGroupLabel elementType={CollapsibleTrigger}>
      帮助
      <ChevronDown className="ml-auto transition-transform group-data-expanded/collapsible:rotate-180" />
    </SidebarGroupLabel>
    <CollapsibleContent>
      <SidebarGroupContent />
    </CollapsibleContent>
  </SidebarGroup>
</Collapsible>
```

## SidebarMenuButton

`SidebarMenuButton` 组件用于在 `SidebarMenuItem` 中渲染菜单按钮。

默认情况下，`SidebarMenuButton` 会渲染一个按钮，但传入 `href` 属性后，它会改为渲染链接。

使用 `isActive` 属性将菜单项标记为活动状态。

```tsx showLineNumbers
<SidebarMenuButton href="#" isActive>
  Home
</SidebarMenuButton>
```

## SidebarTrigger

## 受控侧边栏

使用 `open` 和 `onOpenChange` 属性控制侧边栏。

```tsx showLineNumbers

    <SidebarProvider open={open} onOpenChange={setOpen}>
      <Sidebar />
    </SidebarProvider>
  )
}
```

## 更新日志

### RTL 支持

如果你要从之前版本的 `Sidebar` 组件升级，则需要应用以下更新以添加 RTL 支持：

<Steps>

<Step>为 Sidebar 组件添加 `dir` 属性。</Step>

将 `dir` 添加到解构的 props 中，并将其传递给移动端的 `SheetContent`：

```diff
  function Sidebar({
    side = "left",
    variant = "sidebar",
    collapsible = "offcanvas",
    className,
    children,
+   dir,
    ...props
  }: React.ComponentProps<"div"> & {
    side?: "left" | "right"
    variant?: "sidebar" | "floating" | "inset"
    collapsible?: "offcanvas" | "icon" | "none"
  }) {
```

然后在移动端视图中将其传递给 `SheetContent`：

```diff
  <Sheet open={openMobile} onOpenChange={setOpenMobile} {...props}>
    <SheetContent
+     dir={dir}
      data-sidebar="sidebar"
      data-slot="sidebar"
      data-mobile="true"
```

<Step>为侧边栏容器添加 `data-side` 属性。</Step>

将 `data-side={side}` 添加到侧边栏容器元素：

```diff
  <div
    data-slot="sidebar-container"
+   data-side={side}
    className={cn(
```

<Step>更新侧边栏容器定位类。</Step>

使用 CSS 数据属性选择器替换 JavaScript 三元条件类：

```diff
  className={cn(
-   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex",
-   side === "left"
-     ? "left-0 group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)]"
-     : "right-0 group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
+   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex data-[side=left]:left-0 data-[side=right]:right-0 data-[side=left]:group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)] data-[side=right]:group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
```

<Step>更新 SidebarRail 定位类。</Step>

更新 `SidebarRail` 组件，使其对滑轨使用物理定位：

```diff
  className={cn(
-   "hover:after:bg-sidebar-border absolute inset-y-0 z-20 hidden w-4 -translate-x-1/2 transition-all ease-linear group-data-[side=left]:-end-4 group-data-[side=right]:start-0 after:absolute after:inset-y-0 after:start-1/2 after:w-[2px] sm:flex",
+   "hover:after:bg-sidebar-border absolute inset-y-0 z-20 hidden w-4 ltr:-translate-x-1/2 rtl:-translate-x-1/2 transition-all ease-linear group-data-[side=left]:-right-4 group-data-[side=right]:left-0 after:absolute after:inset-y-0 after:start-1/2 after:w-[2px] sm:flex",
```

<Step>为 SidebarTrigger 图标添加 RTL 翻转。</Step>

为 `SidebarTrigger` 中的图标添加 `className="rtl:rotate-180"`，使其在 RTL 模式下翻转：

```diff
  <Button ...>
-   <PanelLeftIcon />
+   <PanelLeftIcon className="rtl:rotate-180" />
    <span className="sr-only">Toggle Sidebar</span>
  </Button>
```

</Steps>

应用这些更改后，你可以使用 `dir` 属性来设置方向：

```tsx
<Sidebar dir="rtl" side="right">
  {/* ... */}
</Sidebar>
```

侧边栏将在 LTR 和 RTL 布局中正确定位并处理交互。
