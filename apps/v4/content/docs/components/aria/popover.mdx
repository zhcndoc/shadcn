## 用法

```tsx showLineNumbers
import {
  Popover,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover"
```

```tsx showLineNumbers
<PopoverTrigger>
  <Button variant="outline">打开弹出框</Button>
  <Popover>
    <PopoverHeader>
      <PopoverTitle>标题</PopoverTitle>
      <PopoverDescription>此处为描述文本。</PopoverDescription>
    </PopoverHeader>
  </Popover>
</PopoverTrigger>
```

## 组合

使用以下组合构建一个 `Popover`：

```text
PopoverTrigger
├── Button
└── Popover
```
