## 用法

```tsx showLineNumbers
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx showLineNumbers
<AspectRatio ratio={16 / 9}>
  <Image src="..." alt="图像" className="rounded-md object-cover" />
</AspectRatio>
```

## API 参考

### AspectRatio

`AspectRatio` 组件以所需的比例显示内容。

| 属性        | 类型     | 默认值 | 必填 |
| ----------- | -------- | ------- | -------- |
| `ratio`     | `number` | -       | 是      |
| `className` | `string` | -       | 否       |
