## 自定义

你可以通过编辑 `Spinner` 组件，将默认的加载图标替换为其他任意图标。

<ComponentPreview styleName="aria-nova" name="spinner-custom" />

```tsx showLineNumbers title="components/ui/spinner.tsx"
import { LoaderIcon } from "lucide-react"

import { cn } from "@/lib/utils"

function Spinner({ className, ...props }: React.ComponentProps<"svg">) {
  return (
    <LoaderIcon
      role="status"
      aria-label="加载中"
      className={cn("size-4 animate-spin", className)}
      {...props}
    />
  )
}

export { Spinner }
```

## 按钮

为按钮添加加载指示器，以表示加载状态。将 `<Spinner />` 放置在标签之前，并使用 `data-icon="inline-start"` 表示起始位置；或者将其放置在标签之后，并使用 `data-icon="inline-end"` 表示末尾位置。

<ComponentPreview styleName="aria-nova" name="spinner-button" />

## 徽章

在徽章中添加微调器以指示加载状态。将 `<Spinner />` 放置在标签文本之前，并使用 `data-icon="inline-start"` 表示起始位置；或将其放置在标签文本之后，并使用 `data-icon="inline-end"` 表示末尾位置。
