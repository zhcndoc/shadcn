## 使用

```tsx
import { Badge } from "@/components/ui/badge"
```

```tsx
<Badge variant="default | outline | secondary | destructive">徽章</Badge>
```

## 变体

使用 `variant` 属性更改徽章变体。

<ComponentPreview styleName="radix-nova" name="badge-variants" />

## 带图标

你可以在徽章中渲染图标。使用 `data-icon="inline-start"` 将图标渲染在左侧，使用 `data-icon="inline-end"` 将图标渲染在右侧。

<ComponentPreview styleName="radix-nova" name="badge-icon" />

## 带加载指示器

你可以在徽章内渲染加载指示器。请记得为加载指示器添加 `data-icon="inline-start"` 或 `data-icon="inline-end"` 属性。

<ComponentPreview styleName="radix-nova" name="badge-spinner" />

## 链接

使用 `asChild` 属性将链接渲染为徽章。

<ComponentPreview styleName="radix-nova" name="badge-link" />

## 自定义颜色

您可以通过向 `Badge` 组件添加 `bg-green-50 dark:bg-green-800` 等自定义类来定制徽章颜色。

<ComponentPreview styleName="radix-nova" name="badge-colors" />

## API 参考

### Badge

`Badge` 组件用于显示徽章或看起来像徽章的组件。

| 属性        | 类型                                                                             | 默认值       |
| ----------- | -------------------------------------------------------------------------------- | ------------ |
| `variant`   | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"`    | `"default"`  |
| `className` | `string`                                                                         | -            |
