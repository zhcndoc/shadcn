Luma 是为你的下一个应用打造的全新基础。它为组件带来更柔和的表面、更宽松的间距，以及更平静的视觉节奏，同时保留相同的 shadcn/ui 工作流。

和其他新风格一样，Luma 不止于主题调整。它改变了组件的几何形态、间距和整体感受，让你的应用从不同的视觉基准开始。

现已在 [shadcn/create](/create) 中提供，同时支持 Radix 和 Base UI。
