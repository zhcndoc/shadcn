现在，Base
UI 项目已支持新的 [Toast](/docs/components/base/toast) 组件。它支持操作、状态类型、Promise、堆叠以及滑动关闭。

<ComponentPreview styleName="base-nova" name="toast-demo" />

使用 CLI 将其添加到你的项目中：

```bash
npx shadcn@latest add toast
```
