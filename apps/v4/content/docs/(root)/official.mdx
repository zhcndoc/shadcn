shadcn/ui 的官方网站是 [ui.shadcn.com](https://ui.shadcn.com)。

## 官方资源

- **官方网站：** [ui.shadcn.com](https://ui.shadcn.com) 提供官方站点和组件文档。
- **源代码：** [github.com/shadcn-ui/ui](https://github.com/shadcn-ui/ui) 是 shadcn/ui 和 CLI 的官方源代码仓库。
- **CLI 软件包：** [npmjs.com/package/shadcn](https://www.npmjs.com/package/shadcn) 是在 npm 上发布的官方 `shadcn` 软件包。
- **项目动态：** [@shadcn](https://twitter.com/shadcn) 发布官方公告和项目更新。

## 第三方资源

社区网站和注册表可能会使用 shadcn/ui 组件或 shadcn CLI，但除非此页面明确标注由 shadcn/ui 维护，否则它们均为独立项目。

将第三方代码安装到项目之前，请先进行审查。你可以在官方[注册表目录](/docs/directory)中浏览社区维护的注册表。
