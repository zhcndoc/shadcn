# 示例

此目录包含组件文档的演示组件。

## 目录结构

```
examples
├── base
│   ├── button-demo.tsx
│   └── ...
├── radix
│   └── ...
├── aria
│   └── ...
├── __components__   # Auto-generated by registry:build
└── __index__.tsx    # Auto-generated by registry:build
```

## 添加新示例

1. 在 `examples/base`、`examples/radix` 或 `examples/aria` 中创建一个新的 `.tsx` 文件：

```tsx
// examples/base/button-loading.tsx
import { Button } from "@/styles/base-nova/ui/button"

export function ButtonLoading() {
  return <Button disabled>加载中...</Button>
}
```

2. Run the registry build to regenerate the index:

```bash
pnpm --filter=v4 registry:build
```

3. 通过引用示例名称（文件名去掉 `.tsx`）在文档中使用该示例：

```tsx
<ComponentPreview name="button-loading" />
```

## 备注

- 示例文件应直接放在 `examples/base`、`examples/radix` 或 `examples/aria` 中，而不是子目录中。
- 示例从 `@/styles/<base>-nova/*` 导入，其中 `<base>` 可以是 `base`、`radix` 或 `aria`。例如，radix 示例从 `@/styles/radix-nova/*` 导入。
- 聊天组件示例（attachment、bubble、marker、message、message-scroller）应改为从 `@/styles/<base>-rhea/*` 导入。
- 导入样式必须与 MDX 中使用的 `styleName` 匹配。每种 base 的每个样式都会解析到同一个 `examples/<base>` 文件，因此导入决定预览渲染的内容，而 `styleName` 决定 `ComponentSource` 显示的源代码。使用 `@/styles/base-rhea/*` 导入的示例必须使用 `styleName="base-rhea"` 引用。
- Both named exports and default exports are supported.
- After adding or removing examples, run `pnpm --filter=v4 registry:build` to update the index.
